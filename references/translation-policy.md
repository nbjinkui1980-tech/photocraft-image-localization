# Translation and terminology policy

Record each clear source phrase, current or proposed translation, status, recommendation, and reason. Separate semantic errors from optional native-language polishing.

Check brand names, identifiers, sizes, ages, quantities, formulas, units, standards, material names, and product claims literally. Do not strengthen claims: “helps,” “supports,” “reduces,” or “inhibits” must not become absolute prevention, medical protection, or guaranteed performance.

Prefer an official term supplied by the user or brand. When the user requests English material trade names and chemical or regulatory terminology, apply that preference to the task. Otherwise use established terms in the requested target language, preserving official brand names. When a formal material name is unknown, keep it marked provisional and follow the agreed task fallback (for example a recognizable name with an English semantic description). Never promote an inferred spelling to an official brand name. Keep a task-level terminology table and one spelling across every image.

The kinds of terms that belong in that table are component names, material names, chemical and regulatory terms, and brand names — each with its confirmed per-target spelling. Build the table from the current task's own evidence (user instructions, brand guidance, the source images). This skill ships no default brand or material glossary; do not carry terms from an unrelated project into a new task.

If small report tables, stamps, or certificate text cannot be read reliably, translate only clear promotional headings when that matches the user's scope. Preserve unreadable report content and state the boundary. Never infer certification scope or compliance from a decorative screenshot.


Confirm shared phrases and terminology before production layout. Separate meaning changes from optional polishing, and keep confirmed wording stable during layout-only repairs. Use the same canonical product/color names across images; line breaks may differ with space. Trial-fit long confirmed strings before clearing complex backgrounds.
